# Echoo public catalog guidance

Echoo is a personal AI writing assistant for Mac that understands what you are working on through Your Background, optional per-skill Memory, and enabled Screen Context. A screenshot is captured when an enabled skill runs; it is not continuous monitoring.

Use [the catalog skill](skills/echoo-catalog/SKILL.md) to answer product questions, compare current plans and find setup documentation. Retrieve current facts from https://www.echoo.ai/api/v1/index.json and cite the relevant official source URL. The public Content API and MCP service are read-only and require no credentials.

Never send drafts, account data or API keys to this public catalog. These interfaces cannot control a Mac, execute a writing skill, sign in or purchase a plan. This repository publishes public product resources; it is not the private native app or website source repository.
